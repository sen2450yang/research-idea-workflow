# 质量评议：给出判断，不制造精确分数

本表用于选择和改进路线，不要求每次回复逐项展示，也不以所有指标均“良好”为开展探索的前提。

| 维度 | 应回答的问题 | 需要改变路线的信号 |
| --- | --- | --- |
| 重要性 | 回答后改变什么认识、测量或实际决策？ | 只有题目热度，没有具体新增认识或用途 |
| 新颖性 | 相对最接近工作，实质增量在哪里？ | 命题已被回答，却仅换措辞或场景 |
| 解释力 | 能解释哪些已有解释覆盖不了的现象？ | 任何结果都能被事后解释，或只重新命名现象 |
| 可检验性 | 哪些结果支持、削弱或区分解释？ | 没有能够改变判断的观察 |
| 证据成熟度 | 关键前提有多直接的证据？ | 摘要、二手转述、用户判断被当作既定事实 |
| 设计匹配 | 方法是否能回答核心问题？ | 相关性设计承诺完整机制或因果结论 |
| 信息量 | 样本、事件、测量精度与异质性能支撑什么？ | 单位混淆、技术重复充当独立样本、目标不可测 |
| 实施可行性 | 数据、样本、技术和伦理条件是否真实具备？ | 依赖无法获得的关键标签或没有授权的操作 |
| 信息价值与成本 | 最先做哪项工作最能改变判断？ | 无限追加外围模块，核心前提从未验证 |
| 结论边界 | 不同结果分别允许说什么？ | 只有预设阳性故事，阴性结果均被重新包装 |

## 推荐表达

对每个重要候选说明：最强价值、与最接近工作的差异、最关键的不确定性、当前证据程度、可行的下一项验证和建议去向。可使用“优先推进”“先核实关键前提”“保留探索”“调整后再评估”等文字状态。

科学价值、证据成熟度与当前可行性分开判断。暂时不能低成本完成的高价值假说可以保留；容易完成但没有新增认识的研究不因此成为优选。用户明确要求评分时，公开维度、依据、权重和敏感性，不把主观分数伪装为客观概率。

## 交付前的关键检查

检查最重要的事实和引用是否已核实，是否存在被忽视的最相近工作或反证，是否把相关、探索、预测、机制和临床/实际价值混为一谈。回查用户指定范围，确认没有擅自增加下载、分析、安装、实验或本地写入。

检查每项强结论是否有足够直接的设计与证据，每项新增工作是否服务于问题。无法核实的部分应清楚标注，但不能因此回避已经能够做出的判断。

区分构思、检索、核查、设计、执行和验证的状态。文件存在、代码运行、格式检查及工具成功各自只证明对应事项，不证明研究创新成立或实验结果可靠。
